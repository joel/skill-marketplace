Tasks live in `TASKS.md` (Markdown backend, `tasks: markdown` in `workspace.yaml`). Every task follows the task contract: one accountable owner, status, priority, dependencies, acceptance criteria, approval state with a packet path, evidence, next action. Ready work is every task with `Status: ready` whose dependencies are completed; compute it by reading, nothing does it for you. Claim a task by setting yourself as Owner and the status to `in-progress` in one edit, after re-reading the file. Finish it with `Status: completed`, evidence, and a dated line, then move it to `## Completed`. Known issues are tasks under `## Known issues`, never notes in the memory bank. Keep no TODO list anywhere else.
