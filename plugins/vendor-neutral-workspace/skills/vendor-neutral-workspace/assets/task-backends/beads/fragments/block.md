Tasks live in Beads (`tasks: beads` in `workspace.yaml`): the database under `.beads/`, mirrored to `.beads/issues.jsonl`, which is committed. Run `bd prime` for the full workflow context. The loop: `bd ready --json` lists unblocked work; `bd update <id> --claim` takes a task (you become assignee, status in_progress); do the work; `bd close <id> --reason "<evidence>"` finishes it; `bd dolt push` publishes the database to the git remote. Create discovered work with `bd create "<title>" --type task --deps discovered-from:<id>`. Every task carries the task contract: acceptance criteria in `--acceptance`, approval state as a label `approval:<state>` with the packet path in `--external-ref`, evidence in notes. Known issues are `--type bug` tasks. Keep no Markdown TODO list anywhere. On a fresh clone run `bd bootstrap` once, and keep `bd` at the version recorded in `memory-bank/techContext.md` on every machine.
